# awg-agent

HTTP-агент для AmneziaWG: поднимает интерфейс, раздаёт конфиги, показывает
кто подключён. Ставится в докере одним контейнером, управляется ботом
ForestsNet и веб-панелью.

## Зачем свой, если есть amnezia-wg-easy

Три причины, все обнаружились на живых установках.

**Протокол.** Тулзы в образе умеют 3.1 — `HeaderProtectionKey` (3.0),
`RandomTrailers` и `DisableCookies` (3.1). Панель писала в конфиг только
набор 2.0: `Jc/Jmin/Jmax`, `S1..S4`, `H1..H4`, `I1..I5`. То есть сервер
поднимался заведомо слабее, чем мог.

**Сигнатурные пакеты.** `I1..I5` — это датаграмма перед хендшейком,
похожая на обычный DNS-запрос или QUIC Initial: фильтру проще пропустить
знакомый протокол, чем разбирать непонятный шум. Панель подставляла туда
случайные **числа** (`I1 = 104`) — тулзы такое не понимают. Агент
генерирует настоящие пакеты, и каждому клиенту свой: одинаковая
сигнатура у всех и есть та примета, по которой их вычисляют.

**Лицензия.** amnezia-wg-easy — потомок wg-easy 14, а тот
распространяется под CC-BY-NC-SA: **NonCommercial**. Мы продаём готовые
боты, то есть использовали его ровно так, как автор запретил.

## Совместимость

Ручки повторяют amnezia-wg-easy, поэтому бот работает с агентом без
правок, а установка переезжает подменой контейнера:

| Метод | Путь |
|---|---|
| POST | `/api/session` |
| GET / DELETE | `/api/session` |
| GET / POST | `/api/wireguard/client` |
| DELETE | `/api/wireguard/client/{id|имя}` |
| POST | `/api/wireguard/client/{id|имя}/enable` \| `/disable` |
| PUT | `/api/wireguard/client/{id|имя}/name` |
| GET | `/api/wireguard/client/{id|имя}/configuration` |
| GET | `/api/wireguard/client/{id|имя}/qrcode.svg` |
| GET | `/api/health`, `/api/release` |

Два отличия в лучшую сторону:

* клиент ищется **и по id, и по имени** — бот местами ходил по имени и
  получал 404;
* кука сессии называется `connect.sid`. Новые сборки панели переименовали
  её в `wg0.sid`, и уже разошедшиеся боты переставали видеть сессию:
  пароль подходил, а конфиги не создавались.

При первом старте агент читает `wg0.json` от amnezia-wg-easy и переносит
клиентов вместе с ключами и адресами — подмена контейнера никого не
отключает. Параметры обфускации при этом генерируются свои: у старой
панели набор кончается на 2.0.

## Запуск

```bash
docker run -d --name awg-agent \
  -e PASSWORD_HASH="$(htpasswd -nbB admin 'пароль' | cut -d: -f2)" \
  -e WG_HOST=1.2.3.4 \
  -v /opt/awg:/etc/amnezia/amneziawg \
  -p 51820:51820/udp -p 51821:51821/tcp \
  --cap-add NET_ADMIN --cap-add SYS_MODULE --cap-add NET_RAW \
  --sysctl net.ipv4.ip_forward=1 --device /dev/net/tun \
  ghcr.io/forestsnet/awg-agent:latest
```

В `docker-compose.yml` доллары в хэше экранируются удвоением
(`$$2y$$05$$…`): compose интерполирует значения, и без этого в контейнер
уезжает огрызок хэша, к которому не подходит ни один пароль.

## Переменные

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `PASSWORD_HASH` | — | bcrypt-хэш пароля. Без него агент не стартует |
| `PORT` | `51821` | Порт веб-панели и API |
| `WEBUI_HOST` | `0.0.0.0` | Адрес, на котором слушает панель |
| `WG_HOST` | — | Адрес сервера для `Endpoint` в конфигах клиентов |
| `WG_PORT` | `51820` | UDP-порт AmneziaWG |
| `WG_CONFIG_PORT` | `= WG_PORT` | Порт, который попадёт клиенту (если наружу проброшен другой) |
| `WG_INTERFACE` | `wg0` | Имя интерфейса |
| `WG_DEVICE` | `eth0` | Внешний интерфейс для NAT |
| `WG_DEFAULT_ADDRESS` | `10.8.0.x` | Подсеть клиентов |
| `WG_DEFAULT_DNS` | `1.1.1.1` | DNS в конфиге клиента |
| `WG_ALLOWED_IPS` | `0.0.0.0/0, ::/0` | Что заворачивать в туннель |
| `WG_PERSISTENT_KEEPALIVE` | `25` | Keepalive |
| `WG_MTU` | — | MTU, если нужен свой |
| `AWG_PROTO` | `3` | Поколение протокола: `2` или `3` |
| `AWG_RANDOM_TRAILERS` | `1` | `RandomTrailers` (3.1) |
| `AWG_DISABLE_COOKIES` | `0` | `DisableCookies` (3.1) |
| `WG_AUTO_UP` | `1` | Поднимать интерфейс при старте |
| `STATS_TTL_SECONDS` | `1` | Кэш `awg show dump` |

**Внимание:** клиент старее 3.0 к серверу с `HeaderProtectionKey` не
подключится вовсе — заголовки шифрованы, пакеты молча отбрасываются.
Ставить `AWG_PROTO=3` имеет смысл там, где все клиенты свежие.
